Find sounds on Freesound

To search Freesound, the switchboard needs a free API key. You only do this once.

  1. Log in or create an account at freesound.org.
  2. Open freesound.org/apiv2/apply and fill in the short form.
  3. Copy the long code shown as Client secret/Api key and paste it here.
